WA AGENT BASE
ai engine

Cualquier modelo,
por tenant.

OpenAI-compatible: OpenAI, OpenRouter, DeepSeek, Groq, Ollama. Config por tenant en agent_config.ai_*.

  • Session policy — máquina de estados durable (CAS) que decide ANTES de gastar tokens
  • Tools por tenant — buildAgentTools(tenantId): catálogo, órdenes, direcciones, handoff
  • Buffer + dedup — mensajes rápidos se coalescen; replays no duplican respuestas
  • Handoff humano — claims idempotentes, override 24 h, bridge a Chatwoot

docs/ai-engine.md

WA AGENT BASE
seguridad

Fail closed.
Siempre.

1firma HMAC por tenant
2dedup por platform id
3CAS en la sesión
4efectos idempotentes
5rate limit + DLQ

Si la firma, la dedup o el CAS dudan → no hay respuesta. Perder una reply se recupera; mandar dos, no.
