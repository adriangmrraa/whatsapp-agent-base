## Facts (source: repo README.md, docs/)

- Repo: github.com/adriangmrraa/whatsapp-agent-base (MIT, open source)
- Stack: Next.js 16, Drizzle, PostgreSQL, NextAuth, Vercel AI SDK
- Multi-tenant desde el inicio: tenant_id en todo, credenciales AES-256 por tenant
- Providers incluidos: YCloud, Meta Cloud API (OAuth), Chatwoot; adapter nuevo ≈ una clase que implementa MessagingProvider
- Motor IA: OpenAI-compatible por tenant, session policy CAS, buffer+dedup, handoff humano 24 h, DLQ, idempotencia, rate limit, fail closed
